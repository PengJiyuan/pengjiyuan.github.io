## 今日概要

AI圈今日迎来多个重磅事件：Anthropic Claude Code因低级失误泄露51.2万行源代码，成为AI界"核泄漏"事件；NVIDIA DLSS 4.5动态多帧生成正式上线，6倍帧率生成迈入实用阶段；智元机器人宣布第10000台通用具身机器人下线，人形机器人规模量产再提速；港股受AI催化大涨，智谱涨15%、Minimax涨近10%；剑桥研究揭示全球数据中心热岛效应引发关注；摩根士丹利警告AI突破即将到来但能源危机同步逼近。

## 🤖 技术突破

### Claude Code 源码史上最大泄露：51.2万行代码公开，Anthropic 紧急下架

3月31日，Anthropic 遭遇AI史上最严重安全事故——AI编程工具 Claude Code 2.1.88版本因发布打包失误（.npmignore配置缺失），将包含约57MB源映射文件（source map）的51.2万行TypeScript源代码公开发布到npm注册表。代码涵盖约1900个文件，包括未发布功能、内部架构、模型指令和记忆系统架构，一夜之间被数千名开发者搬运至GitHub，浏览量突破2600万次。

开发者从泄露代码中发现了多个未发布功能：类似电子宠物的"KAIKAI"模块（"坐在输入框旁边，对你的编程做出反应"）、代号"KAIROS"的常驻后台Agent系统、以及多Agent协同框架等。Anthropic回应称"这是人为失误，非安全漏洞，无客户数据泄露"，已撤回npm包并向GitHub镜像提交DMCA删除通知。这是Anthropic一周内第二次严重泄露——此前该公司未发布的模型文档草稿已被发现在公开数据缓存中。

来源：[The Verge](https://www.theverge.com/ai-artificial-intelligence/904776/anthropic-claude-source-code-leak) | [Gizmodo](https://gizmodo.com/source-code-for-anthropics-claude-code-leaks-at-the-exact-wrong-time-2000740379) | [CNET](https://www.cnet.com/tech/anthropic-accidentally-exposes-source-code-for-claude-code/)

### NVIDIA DLSS 4.5 动态多帧生成正式上线：6倍帧率生成迈入实用阶段

NVIDIA在GDC 2026期间宣布，DLSS 4.5动态多帧生成（Dynamic Multi Frame Generation）功能于3月31日正式向GeForce RTX 50系列显卡用户推送。该功能基于第二代DLSS Transformer AI模型，可根据目标帧率动态调节帧生成倍率（在0到6倍之间自动调整），兼顾画质、帧率与响应延迟。

从4倍升级到6倍多帧生成，4K路径追踪游戏的帧率提升最高达35%。配合NVIDIA Reflex低延迟技术，额外帧生成对操作响应感的影响降至最低。3月31日起，支持该功能的游戏包括《战地6》《无主之地4》《神鬼寓言：致富之路》《F1 25》《战神：诸神黄昏》《霍格沃茨之遗》《印第安纳·琼斯：伟大之处》《漫威蜘蛛侠2》《怪物猎人：荒野》《星球大战：亡命之徒》等。NVIDIA同时宣布，年内将有20款热门AAA游戏支持DLSS 4.5。

来源：[NVIDIA](https://www.nvidia.com/en-us/geforce/news/dlss-4-5-dynamic-multi-frame-generation-6x-mode-released/) | [TechPowerUp](https://www.techpowerup.com/347230/nvidia-dlss-4-5-dynamic-multi-frame-generation-available-from-march-31)

### 谷歌发布 Java 版 Agent Development Kit（ADK）：企业级AI Agent框架生态补全

谷歌正式发布Java版Agent开发工具包（Agent Development Kit, ADK），补全了其跨语言Agent开发框架的最后一块拼图。此前ADK已支持Python和TypeScript版本。Java版ADK允许开发者用Java语言构建模块化、可复用的AI Agent，支持将整个Agent注册为单一工具供其他Agent调用，并内置GoogleSearchTool等内置工具。

谷歌同时发布ADK Python 2.0 Alpha版本，引入基于图的（graph-based）工作流编排系统，大幅增强复杂Agent系统的编排能力。此外，谷歌发出安全警告：LiteLLM 1.82.7和1.82.8版本在PyPI上发现未授权代码（3月24日），若使用ADK Python的eval或extensions附加组件，需立即更新至最新版本并轮换所有密钥凭证。

来源：[Google ADK文档](https://google.github.io/adk-docs/) | [Google Codelabs](https://codelabs.developers.google.com/adk-java-getting-started)

### AI数学推理逼近极限：GPT-5.4在美国数学奥赛中获95.24分

独立评测机构MathArena发布2026年度美国数学奥林匹克竞赛（USAMO）评测报告：OpenAI的GPT-5.4旗舰模型在六道竞赛题中获得95.24%的得分，与"满分"仅一步之遥。此前一年，同类模型在USAMO面前被评测机构形容为"灾难性失败"——充斥着循环论证、无凭据猜测和前后矛盾。一年间从"胡说八道"到"接近满分"，AI数学推理完成质的飞跃。

来源：[人工智能学家](https://k.sina.com.cn/)

### Morgan Stanley警告：AI重大突破即将来临，但2028年前美国电力缺口或达18GW

摩根士丹利发布重磅研报，警告AI领域"重大突破"将在2026年上半年到来，且速度将"震惊"全球。报告援引OpenAI CEO Sam Altman的判断：未来1-5人公司可击败大型老牌企业；xAI联合创始人Jimmy Ba则预测，递归自我改进AI系统（AI自主升级自身能力）最早将于2027年上半年出现。GPT-5.4"Thinking"模型在GDPVal基准测试中得分83.0%，已达到人类专家在经济任务上的水平。

然而，突破伴随严峻基础设施危机：Morgan Stanley"智能工厂"模型预测，2028年前美国电力净缺口将达9-18GW，相当于电力需求缺口的12%-25%。"Intelligence Factory"瓶颈将成为制约AI扩张的关键掣肘。

### 智元机器人第10000台通用具身机器人下线：人形机器人量产提速

### 剑桥研究警告：全球AI数据中心制造"热岛效应"，周边升温最高达9.1°C

剑桥大学地球观测团队发表最新研究（尚未经同行评议），揭示AI数据中心带来的环境代价：分析过去20年遥感卫星温度数据后发现，全球6000余个超大规模数据中心周边地表温度平均上升约2°C，极端情况下（硅谷集群）高达9.1°C。研究称，这种"热岛效应"在墨西哥巴希奥地区导致约2°C无法解释的升温，西班牙阿拉贡地区升温达2°C；影响范围最远达10公里以外，波及超过3.4亿人口。

此外，数据中心每日消耗1100万至2600万升水（峰值可达日常10倍），加剧水资源紧张；备用柴油发电机排放的污染物预计2030年将在美国造成每年近1300人过早死亡。中国已注意到这一问题，普遍采用冷板式液冷、浸没式液冷等节能技术，并在海南部署海底数据中心降低能耗。

来源：[环球时报](https://www.163.com/dy/article/KPDNQF1G0514R9OJ.html) | [CNN报道](https://www.cnn.com/)
