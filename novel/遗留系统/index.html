第二章：遗留系统

2026-04-06 · 14 分钟 · 2492 字 · PengJiyuan

第二天，我没有回家。

我在公司的机房待了一夜，把能查的资料都查了一遍。我需要理解这套系统到底是怎么来的，为什么会有1989年的时间戳，为什么会有那些我从未见过的代码。

我首先查的是系统的开发记录。

公开资料显示，这套系统是1990年代由一家叫"诺言"的小公司开发的。1990年签约，1992年上线，至今运行了三十四年。

诺言公司，英文名Promise Technology。创始人是一个叫陈维达的人，其他信息几乎没有。这家公司1995年注销，此后再无记录。

我试图找他们的代码仓库。没有。代码在哪儿，我不知道。这套系统的源代码早就丢失了——或者说，从来没有存在过。当年那批人是直接在银行的主机上敲的代码，敲完就走了，没有版本管理，没有文档，什么都没有。

就像一群幽灵建了一座教堂，然后消失了。

我继续深挖公司注册信息。诺言公司成立于1988年。

1988年。

1989年，系统就有了交易记录。1990年，系统才正式开发。

时间线对不上。

一家1988年成立的公司，1989年就能在1990年才开发的系统上产生交易？除非——

除非系统不是1990年开始开发的。除非系统在那之前就已经存在了。

我查了诺言公司的注册地址。在海淀区知春路的一个写字楼里，现在早就拆了，变成了一座商场。我沿着商场一层一层往上走，试图找到当年的痕迹。什么都没留下。只有一家奶茶店。

我坐在奶茶店里，点了杯美式，开始查那七个人的资料。

公司资料里只有七个名字，没有照片，没有履历，只有七个代码：诺言一号、诺言二号……一直到诺言七号。学历那一栏全部写着"自学"。

自学。这个词在1988年的语境里，不像现在这样带着某种浪漫色彩。在那个年代，“自学"的意思是"没有正规学历”。换句话说，这七个人，都是非科班出身。

但他们的代码水平，我昨天已经见识过了。那段我试图反编译的二进制串，加密方式领先了那个年代至少二十年。放在1988年，那种加密方式根本不应该存在。

我开始试图找到更多关于这七个人的信息。我翻了银行内部所有能找到的老档案，给总行档案室打了三个电话，得到的回复都是"相关资料已销毁"。

销毁。这两个字让我感到不安。

什么样的资料会被销毁？过期的、没用的、不再重要的。但一家三十年前就注销的小公司，一套运行了三十年的系统，为什么会有人在今天销毁它的资料？

除非有人不想让这些资料被看到。

我没有放弃。我开始用更笨的方法——我找到了当年参与系统上线的几个老员工，有些已经退休了，有些还在银行系统里工作。 대부분人对这套系统讳莫如深，一听到我问就挂电话。

但有一个人愿意跟我聊。

老赵，六十岁，退休前是银行科技部的工程师。他见证了这套系统1992年的上线仪式，在他的记忆里，那天的合影里有一群年轻女性，但面孔他记不清了。

“那套系统不是他们’开发’的，“老赵在电话里说，“是’移交’的。”

“移交？”

“对。1992年上线那天，有一群人从外面来，把系统移交给银行，然后就走了。走的时候连合影都没拍。我记得很清楚，因为当时我觉得很奇怪——这么大一个项目，上线了连个合影都没有？”

“那群人里有几个女的？”

老赵想了想。“四五个？三四个？我不确定。当时我只顾着看机器，没怎么看人。”

四五个。三四个。不确定。

诺言团队有七个人。

有三四个人，老赵没有印象。

这意味着什么？七个人的团队，有三四个人在最重要的上线仪式上根本没有出现？

或者说——老赵根本没有看到她们？

我没有把这件事告诉老赵。我谢过他，挂断了电话。

下午三点，我回到公司。

老王的工位还是那个样子——电脑关机，水杯还在原位。但今天保洁阿姨来过，他的桌上多了一张便签：

“张kv，你的快递在前台。”

快递？我不记得自己买过什么东西。

我去前台拿了那个盒子。很小，只有巴掌大。没有寄件人信息。盒子上的标签是打印的，内容是一个坐标：

39.9042° N, 116.4074° E

这是北京的坐标。但这个坐标指向的地方很奇怪——在北三环和北四环之间，偏北的位置，周围全是居民区。

我打开了盒子。

里面是一张软盘。

3.5英寸软盘。1990年代常用的那种。上面用记号笔写着一行字：

“Promise-0.1 / 1989.04.15”

1989年4月15日。

正是那笔异常交易的发生时间。

我盯着那张软盘，感觉心脏被什么东西紧紧攥住了。

4月15日。三十七年前的4月15日。那笔0.01元的异常交易。

诺言团队1988年成立。1989年4月15日系统就ready了？然后1990年才正式签约移交？

除非——

除非签约不是真正的开始。除非在签约之前，这套系统就已经存在了。

我必须找到能读这张软盘的地方。

公司的电脑早就没有软盘驱动器了。我去二手市场买了一个USB接口的外置软盘驱动器。花了八十块，摊主说这玩意儿停产十年了。

回到公司，我在一台完全离线的电脑上插上软盘驱动器，插入了那张软盘。

电脑识别到了软盘。里面只有一个文件。

一个.EXE文件。

文件名是：PROMISE.exe

我运行了它。

屏幕闪了一下。没有界面，没有任何可见的输出。只有一个光标在黑色窗口里闪烁了三秒，然后消失。

然后，我电脑的屏幕上出现了一个窗口——一个我绝对没有打开过的窗口。

窗口里只有一行字：

// 找到你了，张kv。

我的后背一瞬间湿透了。

我所有的操作都是离线的。这台电脑没有联网。没有任何外部数据能够进出这台电脑。

但这个程序找到了我。

它怎么知道我的名字？

我试图关掉那个窗口。关不掉。我试图结束那个进程。进程列表里没有这个窗口对应的进程。我试图重启电脑。

电脑没有反应。

屏幕上的那行字变了：

// 别紧张。我只是想见见你。
// 明天晚上九点。
// 知春路112号。
// 一个人来。

然后窗口自动关闭了。电脑恢复了正常。

我坐在那里，心跳快得像要从胸腔里跳出来。

知春路112号。那是诺言公司1988年注册时的地址。现在早就拆了，变成了一座商场。

但我明天会去看看。

我会一个人去。
